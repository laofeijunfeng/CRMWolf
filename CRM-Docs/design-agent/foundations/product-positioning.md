# 产品定位

`/assistant` 是面向销售的 CRM 跟进录入助手，不是通用聊天助手或团队经营查询入口。

## 主链路：跟进 → 商机

- 从自然语言解析客户、跟进记录或会议纪要、下一步动作及时间。使用授权的客户和业务上下文，遇到不明确的对象或缺失的必填信息时先澄清。
- 通过质量与下一步行动门禁后，由服务端签发写入确认。活动保存后，可独立生成商机创建或阶段推进建议；销售承诺和跟进任务仍受活动来源与领域规则约束。
- 不把叙述中的商机信号当作执行授权。商机写命令需经用户确认和领域权限、审批及状态校验；后续动作失败不得回滚跟进记录。

不把线索、合同、回款、发票、License、客户基础信息维护或经营摘要列入当前主链路。不了解或无权读取的信息不得补造。
