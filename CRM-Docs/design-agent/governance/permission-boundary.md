# 权限边界

- **用途：**定义销售助手的权限和数据访问红线。
- **适用范围：**`/assistant` 的解析、任务恢复、业务读取和写命令。
- **权威性：**本文件拥有销售助手的权限边界规则。
- **相关规范：**[销售助手命令契约](../runtime/assistant-command-contract.md)

## 绝对禁止

- 绕过领域写服务和访问策略直接调用业务 CRUD 或写表。
- 访问业务数据拼接权限外上下文，或把模型输出的对象 ID 当作授权。
- 以系统、管理员或其他用户身份替代当前用户写入。
- 绕过审批、通知和领域校验。

## 必须遵守

写命令以当前用户身份，经领域写服务和访问策略执行。服务端从登录上下文取团队与用户，校验对象归属及权限，在提交时复核授权和目标状态；确认只授权当前冻结载荷。

业务服务返回无权限、无数据或校验失败时必须如实反馈；结果未知必须保持待核对，不得改写为成功。

## 允许范围

助手可以按归属访问自有会话、消息、任务、轮次、写命令和幂等记录。团队命令核对仅对获独立授权的核对员开放，不扩大 CRM 读写权限。

这些数据只能用于恢复对话、审计和执行保护，不能替代 CRM 业务对象。
