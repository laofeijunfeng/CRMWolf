# 响应式与移动端

- **用途：**断点、安全区域与滚动边界。
- **适用范围：**foundations 领域。
- **权威性：**本主题是该范围的唯一事实来源；数值见[令牌数值](token-values.md#间距与布局)。
- **相关规范：**[foundations 索引](README.md) · [令牌数值](token-values.md) · [设计系统根入口](../README.md)

## Mobile-first 断点

先满足窄视口任务，再扩展内容空间。导航在可折叠侧栏断点进入对应模式；更大断点逐步扩展布局。SCSS 的 `$bp-*` 必须与 Tailwind `screens` 同值。

| 令牌 | 用途 |
| --- | --- |
| `$bp-xs`（`xs:`） | 小型手机基线。 |
| `$bp-sm`（`sm:`） | 可折叠侧栏起点；以下为移动端。 |
| `$bp-md`（`md:`） | 小桌面布局。 |
| `$bp-lg`（`lg:`） | 大桌面布局。 |

移动端页面内边距由 `--page-padding` 自动收窄；卡片与模块间距按令牌数值中的移动端档。可点目标与输入控件不低于 `--touch-target`。

## 安全区域与视口

| 令牌 | 用途 |
| --- | --- |
| `--safe-top` | 顶部系统区域。 |
| `--safe-bottom` | 底部手势区域。 |
| 移动端视口高度 | 动态移动端视口，见令牌数值。 |

交互目标避开安全区域；移动端高度使用动态视口高度。

## 滚动与密集数据

页面主体不得横向滚动；信息密集表格可在自身容器横向滚动，移动端表格宽度不小于容器、单元格使用令牌数值中的紧凑内边距。表格细则见[表格](../components/table.md)。

移动端优先保留核心列，避免固定像素宽的内容容器。正文与输入字号见[排版](typography.md)。
