# 认证页

- **用途：**登录、注册与团队引导（创建、加入团队）页面的外壳组合。
- **适用范围：**patterns 领域；覆盖未进入团队工作区前的全部独立页面。
- **权威性：**本主题是认证页外壳的唯一事实来源；字段规则见[输入](../components/input.md)，表单规则见[表单页](form-page.md)。
- **相关规范：**[patterns 索引](README.md) · [设计系统根入口](../README.md)

## 外壳

认证页统一使用 `layouts/AuthShell.vue`，页面只提供标题、说明、主体与页脚插槽，不自写卡片、品牌区或页面背景样式。

外壳在视口中居中，宽度使用小号弹窗宽度令牌，圆角与阴影使用卡片的大圆角与一级阴影令牌，标题使用标题字级，说明使用正文字级与弱化色。品牌标识与系统名称由外壳渲染，页面不重复放置。

## 主体与操作

表单使用 crmwolf Field 系列，不直接引用 `ui/form`、`ui/input` 与 `ui/label`。主操作为大号全宽主按钮；并列入口（如创建团队与加入团队）纵向堆叠，次要入口使用描边按钮。

处理中状态禁用主按钮并更新文案，失败后保留已填内容并把焦点移至首个错误字段。

## 页脚与退出

页脚承载切换入口（登录与注册互链）、补充说明或返回上一步，文字居中并使用弱化色。

已登录但尚未进入团队的引导页开启外壳的退出入口，退出前使用 `confirmLogout` 确认，不手写确认弹窗。

## 响应式适配

窄视口不显示卡片边框与阴影，内容直接置于卡片底色上，左右边距使用页面边距令牌并叠加安全区。宽视口（sm 及以上）显示卡片外观，页面背景使用页面底色。
