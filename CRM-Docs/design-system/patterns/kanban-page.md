# 看板页

看板页用于按阶段追踪业务对象的推进状态，适合业务旅程、审批任务和跨模块流程，不用于替代表格列表的精确批量操作。

## 业务旅程看板

- 数据源以 `crm_customer_deal_journeys` 为主；商机、合同、回款和发票只作为关联摘要，不能把业务看板实现成商机列表的另一种展示。
- 阶段列由旅程状态、商机赢率和关联业务闭环动态推断，列标题使用业务语义短文案：初期交流、持续推进、即将签约、签约中、回款中、开票中、已完成、已输单。
- 销售推进阶段按商机赢率分段：初期交流为 0%-49% 或未评估，持续推进为 50%-79%，即将签约为 80%-99%；100% 或已赢单但尚未进入合同处理的旅程也进入即将签约列。
- 正常销售推进阶段使用连续的冷色到正向色表达：初期交流使用 sky，持续推进使用 blue，即将签约使用 emerald。已输单保留 rose，避免红色参与正常推进路径。
- 顶部筛选复用系统筛选组件。首版至少支持最近动态时间和负责人筛选；负责人权限沿用销售看板的 `own/team/all` 可见范围。
- 卡片首屏信息优先级为旅程名称、客户、金额、负责人和右上角最近动态时间。赢率仅在初期交流、持续推进和即将签约中的未赢单销售推进卡片展示；合同、回款、发票数量和预计成交日期默认不展示，避免卡片信息过密。
- 右上角最近动态时间使用轻量状态徽标：0-7 天绿色，8-15 天黄色，16 天及以上红色；无有效时间时使用中性色。

## 组件约束

- 优先使用 `@/components/crmwolf` 已导出的 shadcn-vue 封装，例如 `Badge`、`Card`、`Skeleton`、`ListFilterPopover` 和 `TableToolbarButton`。
- 页面主体应使用固定高度布局；列区域可放在无边框 `Card` 内横向滚动，单列内部纵向滚动。
- 列使用阶段浅色纯色背景，旅程卡片使用白色卡片背景；卡片半径不超过 8px，列头不加下划线。
- 看板卡片内的负责人、赢率和阶段等短文本信息使用[徽标](../components/badge.md)。负责人、赢率和列头数量使用浅底深字；少量关键阶段标签可以保留实心色。
- 颜色使用 shadcn CSS variables 和官方 Tailwind 色阶。阶段浅色可使用 sky、blue、violet、amber、cyan、emerald、rose，但页面背景、中性色和正文必须走语义变量。

## 交互约束

- 首版卡片名称不做点击跳转；后续需要跳转时必须先明确目标详情对象和空关联处理方式。
- 空列显示轻量空状态，不隐藏列；阶段列数量稳定能帮助用户理解业务流程。
- 刷新、筛选、加载和错误态必须可见，且不能导致列宽或卡片高度大幅跳变。
