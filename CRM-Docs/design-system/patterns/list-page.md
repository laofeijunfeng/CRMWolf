# 列表页

- **用途：**筛选、数据展示与分页的页面组合。
- **适用范围：**patterns 领域。
- **权威性：**本主题是该范围的唯一事实来源。
- **相关规范：**[patterns 索引](README.md) · [表格](../components/table.md) · [浮层表面](../components/overlay.md) · [设计系统根入口](../README.md)

## 组合结构

列表页由筛选区、数据表格和分页组成。筛选区位于表格上方，包含条件输入与搜索触发；表格承载可比较的记录集合；分页在表格下方，说明总数与当前位置。

三者共享同一页面上下文，协同完成浏览、检索与定位任务。筛选条件变化后，表格内容即时响应；分页状态与筛选条件相互独立，切换分页不重置筛选。

## 字段能力源

DataTable 列表页的表格列、筛选条件、排序条件和字段配置必须来自同一份字段注册表。DataTable 只接收这份注册表，再按字段能力投影到对应工具。看板、仪表盘等非 DataTable 页面不适用本规则。

业务列默认同时具备列展示、筛选和排序能力。新增业务字段时只修改字段注册表：声明稳定字段 key、标签、类型和列配置，筛选、排序与字段配置会从同一条定义自动产生。不得再维护 `columns`、`filterFields`、`sortFields` 等平行清单，也不得从其中一份清单反推另一份。

关键字、操作列、装饰列等非业务字段不默认开启筛排；确有业务原因需要关闭某个业务列的筛选或排序时，必须显式配置 `false`，并分别提供 `filterDisabledReason` 或 `sortDisabledReason`。不能以“接口暂不支持”为长期关闭理由：已开启的筛选和排序必须在服务端 SQL 查询中针对全量数据执行。

字段类型是前后端契约的一部分。开启筛选或排序时必须声明 `type`；列偏好继续使用前端字段 key，避免破坏已存视图；查询字段与列 key 不同时，仅在对应的 `filter` / `sort` 配置上声明 `apiKey`。前端启用的每个查询 key 和类型必须存在于后端 list-query catalog，并由自动生成的 manifest 与契约测试校验，禁止维护第二份手工后端字段清单。

统一请求协议为：

```json
{
  "filters": [{ "field": "created_time", "op": "after", "value": "2026-08-01" }],
  "sorts": [{ "field": "created_time", "direction": "desc" }]
}
```

服务端必须按“租户与权限范围 → filters → count → sorts → pagination”的顺序执行。未知字段或不支持的操作符返回 400，不得静默忽略。兼容期内，有 `filters` / `sorts` 参数即走新协议，其中 `filters=[]`、`sorts=[]` 也属于显式新协议；仅在参数不存在时读取旧查询参数。

分页 DataTable 禁止先在当前页执行客户端筛选或排序再 `slice`，否则总数与跨页结果必然错误。所有启用的筛选、排序均由服务端对权限范围内的全量结果执行，前端只呈现服务端返回的当前页和 total。

## 筛选与搜索

筛选区按业务场景组织常用条件，默认显示高频选项，更多条件可通过展开访问。条件之间遵循与逻辑；当需任意匹配时，明确说明逻辑关系。筛选、排序和字段配置浮层遵循[浮层表面](../components/overlay.md)的 Panel。

搜索以明确触发方式执行，不随输入即时发起请求。输入遵循[输入](../components/input.md)的标签与校验规则；组合筛选使用[按钮](../components/button.md)提供提交与清空操作。

## 表格与密度

表格用于可跨行比较的记录集合，遵循[表格](../components/table.md)的结构与交互规则。列顺序优先保证主要识别信息可扫描；左侧识别列保持固定，右侧默认不固定。桌面行操作走右键菜单，不占用操作列。

列宽按内容类型分配：标识字段允许适度扩展，数值与日期采用紧凑宽度。表格容器在内容超出视口时允许横向滚动，页面主体不得横向滚动；遵循[响应式与移动端](../foundations/responsive-mobile.md)的滚动边界。

## 空状态与分页

无记录、筛选无结果、加载中、加载失败均须呈现明确状态及后续动作。空状态在表格区域内展示，说明当前情况并提供可执行操作。

分页说明当前页码、总数与每页条数，提供首页、上页、下页、末页与跳转控制。分页信息与筛选条件共同定义数据视图；切换分页不丢弃已填筛选。

## 响应式适配

窄视口优先保留标识，行操作走卡片底部，不依赖桌面操作列；次要信息折叠或移入卡片内容。筛选区收紧为可展开面板；分页简化为核心导航。遵循[响应式与移动端](../foundations/responsive-mobile.md)的断点与安全区域。
