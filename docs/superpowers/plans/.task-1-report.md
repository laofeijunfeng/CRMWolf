## Self-review

- Trend examples for `today=2026-10-12` match the approved table, including explicit two-sided future ends and the latest-complete-month cap for missing-end and end-only windows.
- Empty windows return both bounds as `None`; nonempty windows require closed, ordered bounds.
- Repeated filters intersect lower and upper bounds, while `is_empty`, `is_not_empty`, other fields, and unparsable values do not create bounds.
