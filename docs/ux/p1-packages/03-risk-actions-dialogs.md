# P1-PKG-03 高风险操作与弹窗统一 PRD

- **定位**：高风险操作交互改造包
- **优先级**：P1
- **适用操作**：删除、退回公海、标记输单、转移、撤回、驳回、冲红、修改/删除回款、提交审批
- **不含范围**：Agent / AI 自动化

## 1. 目标

将分散的确认逻辑和临时 modal 收敛到统一的 Dialog / AlertDialog / Sheet 模型，降低误操作、重复提交、关闭丢失和焦点丢失风险。

## 2. 当前问题

`Customers.vue` 中退回公海和标记输单仍存在自定义 modal。与系统其他 Dialog、AlertDialog、Sheet 在焦点、Escape、遮罩关闭、提交中、错误恢复和移动端宽度上可能表现不同。高风险操作被隐藏在右键菜单中时，可发现性也不足。

## 3. 本期需求

### 确认前

- 显示对象名称、对象类型、当前状态和操作后状态；
- 说明影响范围、不可逆后果、审批或通知影响；
- 需要理由时提供 label、校验、字数限制和错误关联；
- 对金额、日期和业务对象进行关键字段复核。

### 提交中

- 显示进行中状态；
- 禁止重复提交；
- 保留当前对象上下文；
- 不允许通过再次点击触发重复请求。

### 成功和失败

- 成功显示实际生效对象、最终状态和下一步；
- 支持时提供撤销，否则展示人工恢复路径；
- 失败保留输入和上下文，并提供重试或人工处理；
- 区分校验、权限、网络、冲突和服务失败。

### 关闭和可访问性

- 统一 Escape、遮罩、关闭按钮和未保存保护；
- 焦点进入 Dialog 并在关闭后恢复；
- 移动端不依赖固定宽度；
- 高风险操作不能只通过右键菜单发现。

## 4. 独立验收标准

- 第一批高风险操作全部使用统一组件；
- 遮罩点击和 Escape 不会意外提交或静默丢失输入；
- 键盘和读屏用户可完成确认、取消和错误修复；
- 移动端无横向溢出，按钮和错误信息可达；
- 每个操作都有可验证的撤销、补偿或人工恢复路径。

## 5. 交付物

- Dialog / AlertDialog / Sheet 选型规则；
- 高风险确认文案模板；
- 通用提交中、成功、失败处理；
- Customers 临时 modal 迁移；
- 高风险操作回归测试。
